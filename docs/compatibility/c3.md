# C3 Highlighting Compatibility

The verified structural C3 backend combines the shared lexical scanner with
the shared tolerant C-like declaration parser. It recognizes modules and
imports, aggregate and fault declarations, direct fields, functions,
parameters, variables and constants, qualified calls, and member access.

The parser is bounded and source-preserving around incomplete declarations. It
does not resolve modules, expand macros, infer types, validate contracts, or
compile the source.
